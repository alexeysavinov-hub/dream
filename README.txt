Лёгкие Сны — прототип сайта (статика для FTP)

Содержимое:
  index.html      — весь сайт одним файлом (главная, каталог, карточка товара, журнал, корзина). Шрифты, скрипты и фото первого экрана уже внутри.
  assets/*.jpg    — фотографии каталога, подгружаются по мере прокрутки (лениво).

Как разместить:
  1. Загрузите index.html и папку assets/ в корень сайта (или в любую папку — пути относительные).
  2. Откройте index.html в браузере. Внешних зависимостей нет, кроме Google Fonts (Cormorant Garamond, Jost) — при их недоступности подставятся системные шрифты.

Это прототип интерфейса: корзина и оформление заказа работают локально, без отправки данных на сервер.
